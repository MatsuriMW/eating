## 怎么上传（不用装任何东西）

1. 打开这个仓库页面，点右上方绿色按钮旁边的 **Add file → Upload files**
2. 把文件或整个文件夹直接拖进去（一个项目建议放一个文件夹，比如 `2026-10 xx项目/`）
3. 页面最下面 **Commit changes** 的框里写一句这是什么，点绿色按钮提交，就传好了

想新建文件夹：在 Upload 之前点 **Add file → Create new file**，文件名写 `文件夹名/README.md`，带上斜杠就会变成文件夹。

## 注意

- 这个仓库是**公开**的，任何人都能看到，别放身份证、合同、聊天截图这类东西
- 单个文件不能超过 25MB（网页上传的限制），大视频可以放网盘，在这里留个链接
